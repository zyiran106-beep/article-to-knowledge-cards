# make-knowledge-cards

把文章或本地 `.md`/`.txt` 文件转换成 5–8 张知识卡片的开源 Skill。

## 1. 项目解决什么问题

读完一篇文章后，要把要点变成能长期记住、能自测的卡片，手工做既耗时又容易出两类问题：一是把整段原文复述成卡片，信息密度低；二是凭印象补上原文没有的解释，看似完整实则失真。

本项目用一套可执行的硬规则把这件事标准化：从原文提取**真正重要的知识**，拆成**一条知识一张卡**，强制四字段结构，并要求**每条实质内容都能回溯到原文**。原文知识点不足时按实际数量输出，不靠拆句或编造凑够 5 张。

## 2. 主要功能

- **输入**：用户直接粘贴的文章正文；本地 Markdown（`.md`）与纯文本（`.txt`）文件。
- **输出**：5–8 张知识卡片；每张固定包含四个字段——标题、核心知识、简明解释、例子或自测问题，末尾附统计行。
- **提取与筛选**：按「支撑主旨 / 关键概念与机制 / 关键数据与边界条件 / 反常识发现」判定重要性；剔除背景、修辞、过渡句与重复表述。
- **去重与拆分**：重复表述合并；一条因果链算一个知识点不拆，两个互不依赖的并列结论才拆成两张。
- **防编造**：只用原文信息；不确定处保留原文的确定性程度；无法回溯的内容删除。
- **防凑数**：知识点超过 8 个按优先级取前 8；少于 5 个按实际数量输出并说明原因。
- **自测设计**：第四字段二选一，必须带 `例子：` 或 `自测：` 前缀；自测题答案须在本卡片内可找到。
- **输出前自检**：逐项核对字段、数量、去重、可回溯性与前缀格式。
- **边界处理**：暂不支持网页抓取/URL、PDF、Anki、图形界面，遇到时用固定句式说明并请用户提供正文或 `.md`/`.txt` 文件。
- **可选元数据**：`agents/openai.yaml` 提供 Codex 界面显示名称、短描述与默认提示词。

## 3. 安装方法

Skill 是一个包含 `SKILL.md` 的目录，目录名必须与 `SKILL.md` 中的 `name` 一致（即 `make-knowledge-cards`）。

- **项目级**（与协作者共享）：把整个 `skills/make-knowledge-cards/` 复制到项目的 `.workbuddy/skills/` 下。
- **用户级**（个人跨项目使用）：复制到 `~/.workbuddy/skills/` 下。

复制后目录结构应为：

```text
<skills 目录>/make-knowledge-cards/
├── SKILL.md              # 必须，技能说明与工作流
└── agents/openai.yaml    # 可选，Codex 界面元数据
```

本项目当前已把 Skill 放在仓库的 `skills/make-knowledge-cards/`，无需额外安装即可查看和校验。

## 4. 使用方法

1. **触发**：直接说“把这篇文章做成知识卡片”，并粘贴文章正文；或给出本地文件路径，例如“把 `tests/fixtures/science.md` 做成知识卡片”。
2. **生成**：Skill 按「获取原文 → 提取知识点候选 → 去重筛选 → 写卡片 → 输出前自检」五步执行，输出卡片与统计行。
3. **边界**：若提供 PDF、网址或要求 Anki/图形界面操作，停止处理并提示改供正文或 `.md`/`.txt` 文件。
4. **校验**（可选）：用官方快速校验脚本检查结构，将其中的 `<skill-creator>` 替换为本机 WorkBuddy 安装目录下的 `skills/skill-creator` 路径：

```bash
python <skill-creator>/scripts/quick_validate.py skills/make-knowledge-cards
```

当前校验结果：`Skill is valid!`

## 5. 输入输出示例

**输入**（粘贴正文，或保存为 `.md`/`.txt`）：

> 光合作用速率受多种环境因素影响。光照较弱时，光合速率随光照增强而上升。当光照增强到某一水平后，光合速率不再增加，这一水平称为光饱和点。温度也会影响光合速率，因为光合作用涉及的酶反应对温度敏感。水分不足时植物会关闭气孔以减少失水。二氧化碳进入叶片主要依靠气孔。

**输出**（完整示例）：

```markdown
### 卡片 1：弱光下光合速率随光照增强而上升

- **核心知识**：光照较弱时，光合速率随光照增强而上升。
- **简明解释**：光照较弱时，光合速率随光照增强而上升。
- **例子或自测问题**：自测：在光照较弱的条件下，光照增强时光合速率如何变化？

### 卡片 2：光饱和点

- **核心知识**：当光照增强到某一水平后，光合速率不再增加，这一水平称为光饱和点。
- **简明解释**：光照增强到某一水平后，光合速率不再增加。
- **例子或自测问题**：自测：什么是光饱和点？

### 卡片 3：温度通过酶反应影响光合速率

- **核心知识**：温度会影响光合速率，因为光合作用涉及的酶反应对温度敏感。
- **简明解释**：光合作用涉及的酶反应对温度敏感。
- **例子或自测问题**：自测：为什么温度会影响光合速率？

### 卡片 4：水分不足时植物关闭气孔以减少失水

- **核心知识**：水分不足时，植物会关闭气孔以减少失水。
- **简明解释**：关闭气孔能减少失水，是植物应对水分不足的方式。
- **例子或自测问题**：自测：水分不足时植物关闭气孔的目的是什么？

### 卡片 5：二氧化碳进入叶片主要依靠气孔

- **核心知识**：二氧化碳进入叶片主要依靠气孔。
- **简明解释**：气孔是二氧化碳进入叶片的主要通道。
- **例子或自测问题**：自测：二氧化碳进入叶片主要依靠什么结构？

本次生成 5 张卡片。
```

说明：若输入只有 3 个独立知识点，则只生成 3 张卡片，末尾统计行按固定句式补上原因，例如 `本次生成 3 张卡片。原文可提炼的独立知识点不足 5 个，未补充外部内容。`

## 测试

`tests/fixtures/` 覆盖四种输入：科普说明文、学术方法论、观点评论、短文本边界；`tests/outputs/` 保存生成结果（首轮 `*.cards.md` 与修订后回归的 `*.cards.v2.md`）。短文本用例验证“不凑数”，其余用例验证卡片数量、字段结构、去重与不编造。
